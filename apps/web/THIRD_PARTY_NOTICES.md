# Dotpol Web — Third-party UI package ledger

These are **runtime dependencies**, not copied upstream source trees or new backends.
The package manager must preserve the upstream licence files in installed packages.
The exact npm package versions, React 19 build and browser integration are checked
in the Phase 1 pull request. Review exact tarballs and generated deployment
attribution before publishing a distributable release.

The Lucide/Feather attribution and ISC/MIT licence obligations remain applicable
when publishing compiled icons. See https://lucide.dev/license and upstream
licence files for the full texts. These packages do not store political data,
invoke AI providers, access source evidence or contact hosted services.

**Status:** direct UI packages are pinned in `apps/web/package.json`;
the real 132-package npm v3 resolution generated by GitHub CI is committed as
`apps/web/package-lock.json` and validated through `npm ci` in two jobs.
This is a **shadcn-style project-owned component subset** using the approved
Radix flavor; no shadcn CLI source tree or full UI registry was bulk-imported.
The component design is original Dotpol adaptation; official shadcn/ui source
patterns are MIT-licensed (https://github.com/shadcn-ui/ui/blob/main/LICENSE.md).
Review component-level licensing, third-party assets and generated distributions.

A complete transitive license inventory, SBOM/security audit and redistributable
NOTICE review remain **outstanding release gates**; this ledger is not a
complete supply-chain audit. Do **not** claim assistant-ui, Lexical,
Perspective or Kepler as installed, and do not claim real model inference.
